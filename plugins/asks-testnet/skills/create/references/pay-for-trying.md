# Pay for trying

An extra on an ask: people get some money just for trying, not only when they win ("pay for sending an
answer", or "pay if it's turned down").

This can't be set up from here yet. **Say:** "Paying people just for trying can't be added to an ask
from here yet. I can post it with a reward for each approved answer instead, or make the reward a
little higher so it's worth trying." Then, on their choice, [post-an-ask.md](post-an-ask.md). Never pass
`pay_on_submit` or `pay_on_reject`.
