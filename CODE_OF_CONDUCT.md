# Code of conduct

Be kind, be constructive, assume good intent. Harassment, discrimination and personal attacks aren't
welcome here, in issues, pull requests or anywhere else in this project.

If something makes you uncomfortable, tell the maintainers privately through a
[security advisory](https://github.com/ixoworld/ixo-plugins/security/advisories/new) (it reaches the
IXO team directly) and we'll deal with it. Maintainers may remove comments or contributions that
break these rules.

This follows the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/).
